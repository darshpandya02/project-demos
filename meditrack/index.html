MediTrack

C#ASP.NET Core 10EF CorePostgreSQLIdentity + JWTRazor Pages

A medical inventory system for hospital drugs and supplies, tracked by lot and expiry date across departments. It has a REST API with JWT bearer auth and Swagger, and a Razor Pages web app with cookie sign-in through ASP.NET Core Identity. Both share one service layer and one set of role policies (Admin, Pharmacist, DepartmentStaff, Auditor). Issuing is always first-expiry-first-out. Every stock row carries an optimistic concurrency token, and every change is written to an append-only ledger.

Rebuilt from scratch in 2026. The original 2022 project code was not preserved. It runs on PostgreSQL or SQLite, not SQL Server.

What the video shows

  • The pharmacist signs in to the Razor Pages app (cookie auth through ASP.NET Core Identity). The dashboard lists low-stock and near-expiry alerts from a freshly seeded database.
  • A new epinephrine lot is received into the ER. The operation page shows the ledger row it wrote.
  • An issue of 35 ondansetron from the ER. The service picks lots first-expiry-first-out and splits the issue across two lots.
  • An issue of 120 acetaminophen drops the ER below its reorder level, and the low-stock alert appears. The expired ibuprofen lot in Pediatrics is listed under near expiry and is never issued.
  • The ER nurse (DepartmentStaff) signs in. The menu has no Receive, Transfer, Adjust or Audit trail, and going to /Stock/Receive directly returns 403.
  • In Swagger UI on the API: a JWT for the nurse from POST /api/auth/token, then POST /api/stock/receive with that token returns 403 and GET /api/alerts/low-stock returns 200 with ER rows only.

The captions were overlaid by the recording script. The browser was driven by scripts/walkthrough.py against a local instance, and the WebM from Playwright was converted to H.264 MP4 with ffmpeg, without edits.

What the terminal recording shows

  • 51 unit tests and 105 integration tests pass. The integration tests use a separate throwaway PostgreSQL 17 database per fixture.
  • The concurrency test sends 50 requests at once through the HTTP pipeline: 40 issues and 10 transfers of 3 units each, 150 units asked for, 100 on hand. Exactly 33 succeed, 17 get 409 Insufficient stock, 1 unit is left, and every unit is accounted for.
  • The control experiment runs the same race with the concurrency token switched off. All 50 issues "succeed", 150 units are issued from 100 on hand, and the shelf still reads 91. With the token: 33 succeed, 99 issued, 1 left.

Measured query speed-up

Audit-trail query (newest 50 plus count) on 50,000 movements, local PostgreSQL 17, 600 samples per case. Before: foreign-key indexes only and a tracked query with Include. After: composite indexes on (PerformedAt), (ItemId, PerformedAt), (LocationId, PerformedAt), plus AsNoTracking with a projection.
