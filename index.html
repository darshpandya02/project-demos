Project demos

Four of my projects are command-line programs, desktop programs or libraries, so there is nothing to click on. This site plays back real terminal sessions of them instead. Each session was recorded with asciinema on my laptop, running the code from the public repositories. The output has not been edited. The gallery images are the program's own output files. The MediTrack page is different: it is a web app, shown as a recorded browser walkthrough plus a recording of its test suite. The two task manager pages show native apps: an Android emulator screen recording, and a macOS app shown as a sequence of window screenshots, each with a recording of its tests.

The site is fully static. Nothing runs on a server: the players replay recorded .cast files, the gallery shows pre-computed images, and the walkthroughs are videos.

~/raft/

raft-cluster-monitor

Raft consensus in C++20, written from scratch. A 5-node cluster: writes, reads, killing the leader, re-election, catch-up after a restart, then a fault-injection run.

 ~/robot-factory/

BSDS PA3: robot factory

A primary-backup replicated C++ service over raw TCP sockets. Client load with latency and throughput, a backup killed and brought back, then the primary killed.

 ~/image-processing/

image-processing-application

A Java MVC image editor, run through its text and script mode. Includes a before/after gallery of every operation on four sample images.

 ~/meditrack/

MediTrack

A medical inventory system in ASP.NET Core and EF Core on PostgreSQL. A browser walkthrough (FEFO issuing, a low-stock alert, a blocked action, Swagger with a JWT), then the test suite and a 50-request concurrency race.

 ~/data-structures/

cpp-data-structures

A header-only C++20 data structure library. Its tests run under ASan, UBSan and TSan, plus a leak check. Then an AVL tree rebalancing insert by insert, hash map rehashing, and a benchmark against the std:: containers.

 ~/taskmaster/

TaskMaster (Android)

A Kotlin task manager on Room with ViewModel and LiveData. An emulator screen recording: create, edit, complete, search, swipe to delete, file export and import, and a WorkManager reminder notification. Then its unit, Room, WorkManager and Espresso tests.

 ~/taskmanager-swift/

TaskManager (macOS, Swift)

A macOS task manager in SwiftUI with an AppKit NSTableView list, on Core Data. A window screenshot sequence of the app (filters, sorting, search, undo, backup), then its Swift Testing suite and the app bundle build.
