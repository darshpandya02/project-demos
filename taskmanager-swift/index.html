TaskManager (macOS, Swift)

Swift 6SwiftUIAppKitCore DataAuto LayoutSwift Testing

A task manager for macOS. The window is SwiftUI; the task list is an AppKit NSTableView hosted through NSViewRepresentable, with cells laid out by Auto Layout constraints and sortable columns. Tasks are stored with Core Data, using a model built in code. It has smart filters with counts, search, undo and redo for every change, JSON export and import, and a menu bar extra.

Rebuilt from scratch in 2026. The original 2022-23 project code was not preserved. Only the macOS app was rebuilt: the iOS (UIKit) app needs full Xcode, which this machine does not have.

How the video was made: not a screen recording

The terminal here does not have the screen recording permission (screencapture reports "could not create image from display" and ffmpeg's avfoundation capture gets no frames), so the video is a sequence of window screenshots. TaskManager --demo-capture DIR runs a fixed list of actions against an in-memory store, through the same AppModel methods the buttons and the table call, and after each step saves the window's own drawing (NSView.cacheDisplay) as a PNG. ffmpeg joins the 42 frames with the hold times the script wrote. Nothing was clicked by hand, and the menu bar extra is not in the frames.

27 tests in 5 suites, all passed locally (Swift 6.3.3) and in GitHub Actions on a macos-15 runner (Swift 6.1.2). The undo test found a bug on the way: changes made in the same run-loop event undid together, so the store now opens one undo group per change.

Not active

  • iCloud sync. CloudKit needs a signed app with the iCloud entitlement and a container on an Apple developer account. The app uses a local SQLite store. The persistence code can build an NSPersistentCloudKitContainer and the model follows CloudKit's rules (a test checks both), but sync has never run.
  • iOS / UIKit. Not rebuilt; there is no iOS target in the repository.
