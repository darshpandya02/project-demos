raft-cluster-monitor

C++20RaftPOSIX sockets

A Raft implementation in C++20 with no dependencies beyond the standard library and POSIX sockets. The replicated state machine is a small key-value store plus a cluster-health table. Every node is a separate raftd process and nodes talk over TCP with a length-prefixed binary protocol. raftctl is the command-line client. It follows redirects to the leader.
