TaskMaster (Android)

KotlinRoomViewModel + LiveDataRecyclerViewWorkManagerEspresso

A task manager for Android. Tasks live in a Room database behind a repository, and the screens follow MVVM with ViewModel and LiveData. The list is a RecyclerView with ListAdapter and DiffUtil, with search, All/Active/Done filters, swipe to delete and undo. A task with a due date gets a WorkManager job that posts a notification on a "Task reminders" channel, with a Mark done action. Backup goes through a BackupProvider interface: a JSON file export and import through the system file picker works; Google Drive does not (see below).

Rebuilt from scratch in 2026. The original 2022-23 project code was not preserved.

What the video shows

  • Four tasks created: one with notes and High priority, one with a due time five minutes ahead (set through the date and time pickers), two more.
  • A task opened and its title edited; a task ticked done; the Done and Active filters; a search for "report".
  • A task swiped away and restored with Undo, then deleted from its edit screen with a confirmation.
  • Export backup through the system file picker, a task deleted, Import backup: the task comes back.
  • The Google Drive backup menu item, which says it is not configured.
  • The reminder for the task due at 22:54 was in the notification shade when the script checked at 22:55:06. The notification's Mark done action completes the task.

The emulator was driven by scripts/demo.py (adb input and uiautomator), which also saved the screenshots.

Not active

  • Google Drive backup. It needs an OAuth client registered in a Google Cloud project for this package and signing key, and none exists. DriveBackupProvider reports itself unavailable and every call fails. Backups go to a file the user picks.
